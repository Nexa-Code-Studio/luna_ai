\chapter{Panduan Antarmuka \& Flow Aplikasi}

\section{Alur Pendaftaran dan Autentikasi}
Pengguna baru diwajibkan melakukan pendaftaran akun melalui aplikasi mobile Luna AI untuk memastikan privasi dan keamanan data konseling.

\begin{enumerate}
    \item Buka aplikasi Luna AI pada perangkat seluler.
    \item Pilih menu \textbf{Daftar Akun} dan isi Nama Panggilan, Email, serta Kata Sandi.
    \item Baca dan setujui \textit{Syarat \& Disclaimer Etika Layanan}.
\end{enumerate}

\section{Sesi Konseling Interaktif \& Voice Call}
Sesi konseling dijalankan secara langsung dengan agen Luna AI berbasis LLM yang responsif dan empati melalui antarmuka percakapan maupun panggilan suara real-time.

\subsection{Langkah Memulai Chat \& Voice Call Konseling}
\begin{itemize}
    \item Tekan tombol \textbf{"Mulai Konseling"} pada bar navigasi bawah.
    \item Pilih moda konseling percakapan atau sesi telepon suara real-time.
    \item Luna AI akan membalas dengan respon empati berbasis metode \textit{Cognitive Behavioral Therapy} (CBT) ringan.
\end{itemize}
